## Запуск приложения

### Локальный запуск

1. Установите зависимости:
```sh
	npm  install
```

2. Выполните
```sh
	npm run start:dev
```

либо  

запустите в одном терминале json-server на (имитация бэкэнда):
```sh
	npm run start:dev:server
```
и запустите в другом терминале сервер разработки:
```sh
	npm start
```
### Запуск скриншотных тестов loki

!! ВАЖНО, для корректной работы требуется  loki не ниже 0.35.1 версии
   Для windows должен быть установлен docker desktop 

1. Запустите в одном терминале storybook:
```sh
	npm run storybook
```

2. (Для windows) откройте приложение docker desktop 

3. Запустите в другом терминале тесты:
```sh
	npm run test:ui
```

### Визуализация отчета скриншотных тестов и обновление скриншотов

1. Запустите в терминале:
```sh
	npm run test:ui:report
```

2. В папке .loki должен сформироватьсф файл с отчетом в котором визуализированы различия report.html.
Данный файл нужно открыть в браузере (open with live server)

3. В случае если все ок - выполнить 

```sh
	npm run test:ui:ok
```
